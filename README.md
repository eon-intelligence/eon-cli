# eon-cli

Release downloads for the `eon` command-line tool. This repository holds release assets only; it contains no source code.

Install on macOS or Linux:

    curl -fsSL https://geteon.ai/install.sh | sh

Each release carries one archive per platform (`eon-<target>.tar.gz`), a `.sha256` checksum beside each, and a `release-manifest.json`. Releases are immutable.
